Outstanding issues

1. XBT values at exactly 3000 m (KI-21)
10 weighted XBT T values sit at exactly 3000 m (12 casts from two 1994–95 cruises). In WOD these casts have only coarse levels with T to 0.1 °C, and at least one is listed as a T-7 XBT (rated to ∼760 m), so they are probably not real XBT measurements at that depth (inferred). They are 0.6–2.7 °C warmer than local climatology; the WOD flags catch only 1 of 12. Rule (chain.xbt_max_depth = 2900): step 06 zeroes XBT values deeper than 2900 m, which removes these 10 values and nothing else; the deep Mediterranean XBT values (to 2800 m) are kept.
Applied in this run (decided 2026-10-27, to be confirmed with the team). Decision pending: team approval of the 2900 m cap.

2. WOD flag extension (chain.wod_flags_extend_levels, KI-19)
WOD standard-level flags only cover standard depths. For values beyond a cast’s deepest standard level, three options: 0 = never extend (safe); 1 = always extend; 2 = extend only when last two levels agree (current default, affects ≤0.09% of values). Decision: formal sign-off on option 2 needed.

Chain notes — WOD flags

WOD quality flags (why we apply them and where they come from)

Every profile from a WOD source (CTD, XBT, Argo/PFL, glider, mooring, MEOP) is accompanied in the World Ocean Database by per-value quality flags at WOD’s standard depths. A flag of 1 means “good”; anything else means the value should be treated as bad and given zero weight in the cost function.

The input files supplied by UCSD (Interp_Profiles) do not carry these flags. UCSD confirmed that their processing pipeline never included them: the prof_Tflag / prof_Sflag arrays in their files are either absent or all zeros. Before this fix, values that WOD flags as bad had full weight in the cost function.

The evidence that this was wrong: the v4r6 optimization dataset does contain WOD standard-level flags in prof_Tflag. Comparing those flags against WOD’s own 2018 export for XBT 1992–1998 gives a 99.4% match. The most likely explanation is that the original MATLAB processing chain fetched the flags directly from WOD — exactly what this Python chain now does.

The chain fetches WOD standard-level flag files from NCEI (paths.wod_std_dir; yearly .gz archives, read with wodpy), matches each profile by WOD cast number, maps the flags to the chain’s 97 depth levels, and writes them as prof_Tflag / prof_Sflag before step 01. Step 06 then zeroes any value whose flag is non-zero.

Effect: XBT T normalized misfit (misfit/σ)² fell from 0.943 (20261021, no flags) to 0.808 (20261027, flags applied), matching v4r6’s 0.802. The remaining gap between our final cost and v4r6’s is explained by γ and sf differences, not data quality.
